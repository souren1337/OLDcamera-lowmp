# PocketRetro Camera

Две самостоятельные версии ретро-камеры для имитации компактных цифровых фотоаппаратов и камер кнопочных телефонов 1980–2000-х годов.

- `android/` — Java + AndroidX CameraX, Android 8.0+ (API 26+)
- `windows/` — C# + WPF + OpenCvSharp, Windows 10/11 x64, .NET 10
- `research/REFERENCE_ANALYSIS.md` — подробный анализ референсов

Это самостоятельная реализация. Проект не содержит APK Dazz Cam, взлома Premium, чужих логотипов или платных ресурсов.

## Что уже реализовано

### Камеры и обработка

Пять переключаемых профилей с разным характером изображения:

- **VGA 2001** — CMOS-шум, полосы считывания, пиксельность и VGA-палитра.
- **CCD 2005** — тёплый оттенок компактной цифровой камеры, более жёсткие света.
- **FILM 1996** — мягкий контраст и цвет фотонегатива.
- **TOY 1988** — сильная виньетка, грубая дискретизация, засветка.
- **NIGHT 2003** — высокая зернистость и вспышечная ночная эстетика.

Выходные разрешения: **0.3 MP (640×480), 0.5 MP (800×600), 0.8 MP (1024×768), 1.2 MP (1280×960), 1.9 MP (1600×1200)**. Кадрирование — 4:3. Размер файла действительно уменьшается до выбранного количества пикселей; это не просто фильтр поверх оригинала.

### Android

- Видоискатель через CameraX.
- Съёмка фото с ретро-обработкой и сохранением в системную галерею.
- Запись видео в SD-качестве; аудио включается при наличии разрешения микрофона.
- Импорт фотографии через системный выборщик/файловый провайдер, обработка и сохранение отдельной копии.
- Импорт видео из галереи или личных папок и воспроизведение внутри приложения.
- Кнопка съёмки, режим Photo/Video, выбор камер под кнопкой съёмки, настройки MP/разрешения, дата и вспышка/фонарик при поддержке устройства.
- Фото: `Pictures/PocketRetro`; видео: `Movies/PocketRetro`.

**Ограничение Android v1:** видео записывается в SD-разрешении, но пока не проходит через полный покадровый движок ретро-эффектов. Импортированное видео можно выбрать и просмотреть внутри приложения. Обработка фото реализована полностью.

### Windows

- Видоискатель с веб-камеры или USB-камеры.
- Фото и видео с применением выбранного профиля.
- Импорт фото из любой папки, обработка и сохранение отдельного файла.
- Импорт видео из любой папки, покадровая обработка и экспорт новой версии в MJPEG AVI.
- Выбор камер под кнопкой съёмки, режим Photo/Video, 0.3–1.9 MP, имитация вспышки и дата.
- Фото: `%USERPROFILE%\Pictures\PocketRetro\Photos`; видео: `%USERPROFILE%\Videos\PocketRetro`.

**Ограничение Windows v1:** обработанные ролики экспортируются в AVI/MJPEG без переноса звуковой дорожки. Исходный файл не изменяется.

## Сборка Android

Нужно установить Android Studio, Android SDK Platform 36, JDK 17 и Gradle 8.13.

1. Откройте каталог `android/` как существующий Gradle-проект в Android Studio.
2. Дождитесь Gradle Sync и установки Android SDK Platform 36.
3. Подключите телефон с USB debugging или запустите эмулятор с камерой.
4. Выберите конфигурацию `app` и нажмите **Run**.
5. Разрешите доступ к камере. Для записи звука в видео разрешите микрофон.

APK можно собрать через **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Полученный APK будет debug-сборкой, пока не настроите собственную подпись.

Версии инструментов закреплены в Gradle-файлах. CameraX 1.6.2: https://developer.android.com/jetpack/androidx/releases/camera

## Сборка Windows

Нужно установить Windows 10/11 x64 и .NET 10 SDK либо Visual Studio 2022 с компонентом **Разработка классических приложений .NET**. Веб-камера нужна только для живой съёмки; импорт файлов работает и без неё.

Откройте PowerShell в `windows/PocketRetro.Windows/` и выполните:

```powershell
dotnet restore
dotnet build -c Release
dotnet run -c Release
```

Для автономной x64-публикации:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true
```

Папка результата: `bin/Release/net10.0-windows/win-x64/publish/`.

## Архитектура

- `android/.../RetroProcessor.java` — обработка статичных изображений: даунсемплинг, шум, полосы, цветовой сдвиг, виньетка, засветка, дата.
- `android/.../CameraProfile.java` — профили камер Android.
- `windows/.../RetroEngine.cs` — общий OpenCV-пайплайн фото/видео Windows.
- `windows/.../CameraLook.cs` — профили Windows.
- `windows/.../MainWindow.xaml` — интерфейс Windows.

## Конфиденциальность

Облачной обработки, аналитики и сетевых API нет. Файлы обрабатываются локально, оригиналы не перезаписываются.
